# docs/ — Vault do Obsidian

Esta pasta é um **vault do Obsidian** com a documentação do projeto.

## Como abrir
1. Instale o [Obsidian](https://obsidian.md)
2. `Open folder as vault` → selecione esta pasta `docs/`
3. Comece pela nota [[Home]]

Tudo aqui é Markdown normal — funciona no GitHub também. Os links `[[assim]]` viram navegáveis dentro do Obsidian (com grafo e backlinks).

## Opcional: ignorar configs do Obsidian no Git
Se não quiser versionar suas preferências pessoais do Obsidian, adicione ao `.gitignore`:
```
docs/.obsidian/
```
